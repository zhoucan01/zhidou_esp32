# NTC独立计算及电机运行趋势接纳

删除NTC备用均值后，继续消除间接耦合：原三路共用主温度来选工况配比、判98℃降温、切换并清空全部窗口。现改为按通道索引独立温度、ADC趋势、降温锁存、阶段初始化、工况和清窗。无全局主温度参与ntcTemp内部计算。设备电源/加热/RPM反馈仍共享，这是共同工况而非探头数值。

每路新增20个可信ADC对应时间戳。电机运行时，至少8点且跨度140ms的自身历史可拟合ADC斜率；历史与新点的拟合残差都不超过40 ADC、相邻差不超过200、斜率不超过1000 ADC/s、最新历史不超过2秒才允许接纳。保留每路原始ADC/温度多层过滤。无历史、历史过期或跑偏时保持该路旧值，不借其他NTC恢复。DataCenter允许机器3进入上述运行中校验路径，并通过新鲜接纳标志避免旧值重复计入98℃窗口。
