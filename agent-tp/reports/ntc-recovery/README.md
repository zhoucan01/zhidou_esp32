# 断档后稀疏采样重新接纳

问题：ADC及温度候选的相邻间隔原先不得超过100ms，恢复后若始终按200ms或1秒采样，异常新水平的候选计数会反复清零，导致可信历史停在旧值。

修改：两个候选层共用的最大间隔调整为2秒（包含边界）。保留8点、至少140ms、方向、极差、变化速率以及有效范围等检查，不以单点重置可信基准，不补算断流时间；更长断流仍打断候选，之后需重新积累8点。温度模式维持已移除自动备用均值切换后的行为：只用配置的主通道，未更新时保留该通道自身有效历史。

验证：运行 agent-tp/tests/firmware/test_ntc_reaccept.py。新增断档3秒后分别按200ms、1秒、2秒节拍恢复的ADC/温度双层用例，前7点不更新、第8点重新接纳；保留超限间隔清候选测试。原交替尖峰、七点突发、重复时间、无效ADC、实际时间与温度斜坡、主通道失效/恢复等回归全部通过。测试使用真实生产滤波代码和可控时钟，不能替代实机采样节拍验证。更稀疏或持续不一致的数据仍可能保持旧值，这是有限证据下的拒绝策略。
