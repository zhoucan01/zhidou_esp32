# 1150 mL、7档高温升温数据库补充

数据源：`agent-tp/data/captures/2026-10-29/20261029-233558-561446.csv`及同名`-serial.txt`。用户确认实际水量1150 mL。固件为MACHINE=3；CSV的本地MACHINE=4只用于上位机本地拟合，不作为数据库机型依据。

## 入库范围

90～93℃日志仍为9档，本次没有把这些数据标记为7档。首个有效CRC的7档加热回显为23:40:38.140；随后模式6按开5秒/停5秒，模式7按开6秒/停4秒运行，电机均为1档、开3秒/停3秒。周期停热时仍归属于对应升温工况，不作为降温数据。

只处理NTC事件，按NTC接收时间去重；参考温度只使用真实温度事件并按真实温度接收时间去重、线性插值，不用CSV重复缓存值。最大允许参考点间隔2秒，超过即剔除；不延用上位机控制所允许的10秒期限。站3回包均验证CRC；电机停止写确认满500 ms且最近500 ms内实测RPM=0才接纳。首个7档确认之前、冷却/全停后及非7档工况排除。ADC限于1～4094，不按拟合残差删点。

全部593个NTC事件中，305个不在目标升温范围；288个7档候选中剔除电机未停止满500 ms的155个、转速非零或过期的27个、参考温度间隔过大的14个，接纳92个（31.94%）。覆盖温度93.1639～97.9873℃，不声称覆盖90～93℃或98℃以上。

## 复现

```bash
PYTHONDONTWRITEBYTECODE=1 python3 agent-tp/tools/temperature/import_gear7_heating.py \
  agent-tp/data/captures/2026-10-29/20261029-233558-561446.csv \
  --serial agent-tp/data/captures/2026-10-29/20261029-233558-561446-serial.txt \
  --water-ml 1150 --write
```

不带`--write`只输出候选表及报告数据，不修改生产表。输出包括`accepted_samples.csv`（92个对齐样本）、`metrics.json`（筛选与误差）、`gear7_heating_table.inc`（完整合并候选）。新增辅助产物均归档在agent-tp；编译产物保存在build。
