## 代码原因

数据库已有7档：NTC1开5停5曲线仅覆盖ADC 1747.529～1771.941（93.707～94.534℃），开6停4覆盖1652.6～1731（95.2～97.9℃）。默认工况模板却只有19/10/9/8档，7档被构造成电机0档、节奏-1的未知工况。旧的只选一条最近曲线逻辑可能持续选择窄的5/5曲线，超过5℃外推界限后保持旧值；其上限与日志冻结值接近，但这不是已确认的设备版本复现。

工作区此前已有优先选择覆盖ADC的曲线和电机恢复修复，本次保留。缺档回退还被新增的最大3档距离限制截断；相差更远时没有候选，并非无条件最近档位。

## 本次变更

- 默认模板补充7档95℃（加热5/5秒、电机3/3秒）与98℃（加热6/4秒、电机3/3秒）。
- 未列入模板的档位，先按档位差、再按本通道温度阈值距离推断模板节奏，保留实际请求档位供数据库查询；不再填写未知负时间。
- 移除3档距离硬限制。数据库继续按同通道、同加热/降温相位查询，先选择覆盖当前ADC的最近曲线；无覆盖时保留原5℃外推限制及无效时保持旧值行为。
- 不改动测温数据库、不放宽ADC异常、电机及趋势滤波保护。缺档借用的曲线是估计，不能保证与实测同档精度相同。
