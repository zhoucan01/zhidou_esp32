# 原始测试数据

本目录说明文件可纳入版本控制，`captures/`、`testdata/`、`communication/`中的原始数据留在本地并由工程`.gitignore`忽略。整理不删除原始数据，也不进行拟合或修改采样值。

## 上位机采集

`captures/YYYY-MM-DD/`按采集文件名的开始日期归档，CSV和同名`-serial.txt`放在一起。上位机后续采集也写入这个位置。

整理时盘点：

| 日期 | CSV | 串口日志 | 配对情况 |
|---|---:|---:|---|
| 2026-10-26 | 5 | 5 | 完整配对 |
| 2026-10-27 | 14 | 15 | 有一份串口日志没有对应CSV |

缺少CSV的会话为`20261027-125905-853024`：本次源目录只有`-serial.txt`，没有生成或补造CSV。引用该CSV的历史命令需要先补齐数据，不能直接运行。

例如最近一次完整采集：

```text
agent-tp/data/captures/2026-10-27/20261027-232523-940824.csv
agent-tp/data/captures/2026-10-27/20261027-232523-940824-serial.txt
```

- `testdata/ntcdata/dev3/`：原`dev3`标签下的6份CSV，含200V、210V、220V、230V、240V等原文件名前缀。
- `testdata/ntcdata/dev5/`：原`dev5`标签下的`20261027-232523-940824.csv`。
- `testdata/flow/202149.log`：流程原始日志。
- `communication/2026-09-24/115226.log`：原`agent-qs/batter/260924/`下的通信日志。

上述样机标签和电压前缀按原目录及原文件名保留，不据此推断固件的`MACHINE`宏。一些CSV与采集目录中的文件可能相同，仍保留测试分组中的副本，方便追溯来源。

历史文档可能引用未随工程提供的其他日期数据。路径整理不代表这些历史数据已补齐。
